Gestione della lingua con le annotation [Display] in ASP.NET Core
Sì, è possibile gestire la localizzazione (lingua/traduzioni) utilizzando le annotation [Display] in ASP.NET Core attraverso il sistema di risorse (resource files). Ecco come farlo:

Metodo 1: Utilizzo diretto delle risorse
csharp
[Display(Name = "UserName", ResourceType = typeof(Resources.Models.User))]
public string Username { get; set; }
Dove:

Resources.Models.User è la classe generata dal file di risorse (User.resx)

"UserName" è il nome della chiave nel file di risorse

Metodo 2: Configurazione del localization service
Configura il servizio in Program.cs:

csharp
builder.Services.AddLocalization(options => options.ResourcesPath = "Resources");

builder.Services.AddControllersWithViews()
    .AddViewLocalization()
    .AddDataAnnotationsLocalization();
Crea i file di risorse nella cartella Resources:

Resources/Models/UserModel.en.resx (inglese)

Resources/Models/UserModel.it.resx (italiano)

Resources/Models/UserModel.fr.resx (francese), ecc.

Usa l'annotation nel tuo model:

csharp
[Display(Name = "Email", ResourceType = typeof(UserModel))]
public string Email { get; set; }
Metodo 3: Utilizzo con IStringLocalizer
Per una maggiore flessibilità:

csharp
public class UserModel
{
    private readonly IStringLocalizer<UserModel> _localizer;

    public UserModel(IStringLocalizer<UserModel> localizer)
    {
        _localizer = localizer;
    }

    [Display(Name = "Email")]
    public string Email { get; set; }

    public string EmailDisplayName => _localizer["Email"];
}
Esempio completo
File di risorse italiano (Resources/Models/User.it.resx):

text
Name    | Value
--------|---------
Email   | Indirizzo email
UserName| Nome utente
File di risorse inglese (Resources/Models/User.en.resx):

text
Name    | Value
--------|---------
Email   | Email address
UserName| Username
Model class:

csharp
[Display(Name = "Email", ResourceType = typeof(Resources.Models.User))]
public string Email { get; set; }

[Display(Name = "UserName", ResourceType = typeof(Resources.Models.User))]
public string Username { get; set; }
Configurazione della cultura
Per cambiare lingua, imposta la cultura corrente:

csharp
// Imposta italiano
Thread.CurrentThread.CurrentUICulture = new CultureInfo("it-IT");

// Imposta inglese
Thread.CurrentThread.CurrentUICulture = new CultureInfo("en-US");
Questo sistema permette di avere testi visualizzati diversi a seconda della lingua selezionata dall'utente, mantenendo il codice pulito e separando le risorse di traduzione dal codice.
